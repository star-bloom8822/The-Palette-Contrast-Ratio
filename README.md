# The-Palette-Contrast-Ratio
An interactive web game and utility designed to help creators test color pairings and master WCAG web accessibility standards with ease.

✨ Features:
- **🎮 Game Mode:** Challenge yourself to find accessible color combinations against strict WCAG standards under randomized brand themes.
- **🛠️ Custom Utility Mode:** Quickly check your own custom hex codes, swap foreground and background colors, or apply quick-access presets (Light Mode & High Contrast).
- **📱 Fully Responsive:** Optimized layout that looks great on both mobile (portrait and landscape) and desktop screens.
- **📋 One-Click Copy:** Easy to copy your color codes to your clipboard.
- **📖 Built-in Handbook:** Learn the difference between AA (normal) and AAA (enhanced) accessibility compliance standards within this website.
